# 🧟 僵尸一笔画符 · 一笔画阵

经典《一笔画》解谜 + 僵尸逼近的恐怖倒计时小游戏。`index.html` 双击即玩，无需任何依赖。

> 背景图为 AI 生成的僵尸场景 `bg.jpg`，需与 `index.html` 放在同一目录；替换同目录下的 `bg.jpg` 即可换背景。
> 僵尸头部为透明 PNG `zombie-head.png`（替换同名文件即可换头），通过 CSS 绝对定位对齐原 SVG 头位，保留随僵尸走近而加速的摆动动画。

## 玩法

- 每关一只僵尸，从远处向黄纸逼近，**60 秒**内扑到面前。
- 用朱砂在黄纸上一笔画完**所有路线**（每条路线只能走一次，节点可重复经过），符成则击退僵尸，进入下一关。
- 点红点落笔、按住拖动连线，也可以点选相邻节点连线；`撤销` / `重画` 不扣时间，但僵尸不会等你。
- 越早画完，符力越强：

| 用时 | 符力 | 特效 |
| --- | --- | --- |
| ≤ 15s | 神符·天雷 ⚡ | 金色闪电 + 冲击波，僵尸焚为灰烬，+1000 分 ×3 |
| ≤ 30s | 灵符·真火 🔥 | 火浪爆发，僵尸被击飞，+600 分 ×2 |
| ≤ 45s | 朱符·罡风 🌪 | 罡风震退僵尸，+300 分 ×1.5 |
| ≤ 60s | 残符·微光 ✨ | 微光勉强逼停僵尸，+100 分 ×1 |
| > 60s | ☠ 僵尸扑脸 | 闯关失败 |

- 僵尸走近后心跳声加速、画面红瞳脉冲；无限关卡，每关一种僵尸（行尸 / 跳尸 / 毛僵 / 飞僵 / 尸王……），最高分存入本地。

## 运行

- 直接双击 `index.html` 在浏览器打开（推荐 Chrome / Edge / Safari）；
- 或者本地起个静态服务器：`python3 -m http.server 8000` 后访问 `http://localhost:8000`；
- 支持手机触屏（pointer events），建议竖屏游玩。

## 技术要点

- 零依赖：原生 JS + SVG + CSS + WebAudio（音效全部实时合成，无外部资源）；背景图 `bg.jpg` 通过 CSS `background: center/cover` 铺满全屏，并叠加一层上下渐晕暗色遮罩保证黄纸、僵尸与 HUD 的可读性。
- 谜题生成器保证**每关必有解**：随机轴对齐矩形环并集（天然可一笔画）→ 奇偶修复（只增边、不删边，节点规模不回退）→ 加一条相邻新边制造经典“双奇点”路径题；同一关题目确定，重试不变。
- 难度曲线：4 节点教学关 → 9 → 12 → 14 → 19 → 23~25 节点 / 最多 33 条边（5×5 网格封顶）。
- `tests/gen-test.js`：用 Node 直接 `eval` 提取页内脚本，对 1~80 关做连通性、奇度点 ≤ 2、Hierholzer 欧拉可解性、确定性校验。

## 测试

```bash
node tests/gen-test.js        # 生成器单元测试（连通性/奇度点/欧拉可解/确定性，1~80 关）
node tests/browser-smoke.js   # 无头 Chrome 冒烟 1：启动 → 开始 → 解出第 1 关 → 自动进入第 2 关
node tests/browser-smoke2.js  # 无头 Chrome 冒烟 2：僵尸逐秒逼近、符力降级、61s 扑击失败、再战复位（约 75 秒）
node tests/browser-smoke3.js  # 无头 Chrome 冒烟 3：拖动连线、重复路线报错反馈
```

浏览器冒烟测试需要 macOS 上装有 Chrome（默认路径 `/Applications/Google Chrome.app`）。
